# Cerimonialista Stephany Mury — Landing Page

Site institucional desenvolvido para profissional de cerimonial e eventos. Focado em apresentação de serviços, portfólio e captação de clientes.

🔗 **[Ver site ao vivo](https://www.cerimonialistastephanymury.com.br)**

---

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

---

## ✨ Funcionalidades

- Apresentação dos serviços oferecidos
- Seção de portfólio de eventos realizados
- Formulário / botão de contato
- Design responsivo para mobile e desktop
- Navegação entre páginas internas

---

## 📁 Estrutura do Projeto

```
├── index.html          # Página principal
├── pages/              # Páginas internas
├── css/                # Estilos
├── js/                 # Scripts
└── assets/             # Imagens e mídias
```

---

## ⚙️ Como Rodar Localmente

Não requer instalação. Basta abrir o arquivo no navegador:

```bash
# Clone o repositório
git clone https://github.com/Paulo-Mury/Cerimonialista-Stephany-Mury.git
cd Cerimonialista-Stephany-Mury

# Abra no navegador
open index.html
```

Ou use a extensão **Live Server** no VS Code para desenvolvimento com hot reload.
